# Goose 旧品牌资产备份

- @author logic
- @date 2026-08-14

本目录是替换为 `src/images/logo.png` 新品牌之前的旧 Goose 品牌资产完整备份，仅作留存，不参与构建与打包（不在 `src/` 内，不会进安装包）。

- `images/`：`ui/desktop/src/images/` 替换前的全部文件原样副本（icon.svg 矢量源、icon.ico/icns/png 各平台图标、iconTemplate* 托盘图标、glyph*.svg 托盘源、prepare.sh 旧生成脚本、loading-goose 旧加载动画等）
- `ui-components/`：三个旧 logo 组件替换前的原样副本（含 Rain 雨点动画的内联 SVG 源码）

如需恢复旧品牌，将对应文件复制回 `ui/desktop/src/images/` 与组件原位置即可。
