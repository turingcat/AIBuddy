# Desktop Toolbar And Account Menu Alignment Design

## Goal

统一 HeyBuddy 桌面端聊天输入区所有图标文字按钮的字号，并让左下角账号弹出菜单始终与账号触发按钮等宽，避免越过侧栏与主窗口的分界线。

## Toolbar Typography

聊天输入区以现有模型、目录、上下文、扩展和附件控件使用的 `text-xs` 为统一标准。

`ChatInput` 自己渲染的以下宽工具栏辅助按钮统一应用 `text-xs`：

- 诊断
- 附件
- 语音

发送和停止属于输入区主操作，保留通用按钮现有的 `text-sm`，字号比辅助按钮更大。

窄工具栏仍只显示图标，不改变现有控件取舍、按钮尺寸、可用状态或业务逻辑。模型、目录、上下文和扩展已经使用 `text-xs`，只增加测试确保整体约定不会回退。

## Account Menu Width

账号菜单不再使用固定的 `w-64`。菜单宽度绑定 Radix Dropdown Menu 提供的触发器宽度变量，使弹出菜单与左下角账号按钮等宽。

侧栏支持动态调整宽度，因此菜单必须随触发器同步变化。保留现有向上弹出、左对齐、账号摘要、余额刷新、设置和退出登录行为。

## Testing

- 扩展 `ChatInput` 测试，覆盖诊断、附件和语音在宽工具栏中的 `text-xs` 样式，并确认发送和停止保留 `text-sm`。
- 保留窄工具栏测试，确保窄模式仍隐藏文字。
- 扩展 `UserAccountMenu` 测试，断言菜单使用触发器宽度变量且不再使用固定 `w-64`。
- 运行相关测试、桌面端全量测试、类型检查、变更文件 Prettier 检查和打包签名。

## Verification Boundary

自动验收不再启动桌面应用或生成截图。最终 `.app` 由用户人工启动并确认字号及菜单边界。
